# 코드 목표
01.simple-agent는 spring-ai 기반으로 agent를 이해하고 스스로 코딩을 할 수 있도록 지원하는 샘플코드이다.
본 코드는 복잡하게 작성하지 않고 Spring AI에서 Agent는 무엇이고 어떻게 구현하는지 이해하는데 목적을 두어야 한다.
Agent의 역할은 Simulation 형태로 만들어서 @Tool을 활용해서 스스로 작업하도록 한다. 

# 작성 방법
모든 Tool은 가상의 데이터를 가지고 동작하게 한다.
그리고 각 Tool에서 사용하는 데이터는 {Agent 명}.json로 만들고 소스는 resource/data 밑에 만들어진다.
텍스트 데이터는 가상 데이터로 채워넣고 json 형태로 저장된다. 
이 것은 향후 Multi-Agent 시나리오를 위해 사용된다.

# 규칙
이미지 아이콘을 사용하지 않는다.
코드는 복잡하지 않고 교육을 위한 것으로 단순화하고 예외처리 및 로그를 많이 넣지 않는다. 
단, 학습 과정에 대한 흐름을 표시하는 로그는 넣을 수 있다.
커멘트가 필요한 경우 한줄짜리 간단하게 넣는다. 
spring AI 를 사용하고 maven 기준으로 작성한다. 
tymeleaf로 간단하게 agent 별 실행 과 결과를 볼 수 있는 UI를 제공한다. (화려하지 않고 심플하지만 깔끔하게)

# 시나리오
사용자가 출장 지역, 날짜, 예산을 입력하고, 요청할 Agent(교통편/숙소/식당)를 선택한 뒤 요청 프롬프트를 입력한다.
선택된 Agent 하나가 자신의 Tool 데이터 안에서 요청 프롬프트에 맞게 답변한다.
별도의 평가/검토 Agent는 없다.

공통 동작 규칙 (모든 Agent 동일)
- 반드시 자신의 Tool을 호출해서 데이터를 조회한 뒤 답한다.
- Tool이 제공한 데이터만 근거로 답하고, 없는 항목을 지어내지 않는다.
- 사용자 요청에 기준(빠른 것, 저렴한 곳, 개수, 음식 종류 등)이 있으면 그 기준을 최우선으로 따른다.
- 요청에 별도 기준이 없으면 Agent별 기본 규칙을 적용한다.

1. 교통편 Agent
역할

출장 지역까지 이동할 교통편에 대한 요청에 답한다.

사용할 Tool
getTransportationOptions(destination)

Tool은 교통편 데이터를 단순히 반환한다. (가격은 편도 기준)

무궁화호: 28,000원, 5시간 30분
고속버스: 35,000원, 4시간
KTX: 60,000원, 2시간 30분
KTX 특실: 85,000원, 2시간 30분
비행기: 100,000원, 1시간
비행기 비즈니스: 180,000원, 1시간

기본 규칙 (요청에 기준이 없을 때)
왕복 비용 = 편도 가격 x 2 로 계산한다.
왕복 비용이 전체 예산의 30% 이내인 교통편 중 가장 빠른 것 1개를 선택한다.
해당되는 것이 없으면 가장 저렴한 것을 선택한다.

답변에 포함할 내용
교통편 이름, 비용(편도/왕복), 추천 이유

요청 예
"가장 빠른 교통편을 추천해줘"
"가장 저렴한 교통편 3개를 비교해줘"

2. 숙소 Agent
역할

출장 기간 동안 사용할 숙소에 대한 요청에 답한다.

사용할 Tool
getHotelOptions(destination)

Tool은 숙소 데이터를 반환한다.

캡슐호텔 E: 1박 30,000원, 회사까지 2km
게스트하우스 C: 1박 50,000원, 회사까지 5km
비즈니스호텔 A: 1박 80,000원, 회사까지 1km
호텔 B: 1박 120,000원, 회사까지 500m
프리미엄호텔 D: 1박 200,000원, 회사까지 300m

기본 규칙 (요청에 기준이 없을 때)
총 숙박비 = 1박 가격 x 숙박 일수 로 계산한다.
총 숙박비가 전체 예산의 40% 이내인 숙소 중 회사와 가장 가까운 곳 1개를 선택한다.
해당되는 것이 없으면 가장 저렴한 곳을 선택한다.

답변에 포함할 내용
숙소 이름, 비용(1박/총 숙박비), 회사까지 거리, 추천 이유

요청 예
"회사에서 가까운 숙소 2곳을 알려줘"
"가장 저렴한 숙소를 추천해줘"

3. 식당 Agent
역할

출장 중 이용할 식당에 대한 요청에 답한다.

사용할 Tool
getRestaurantOptions(destination)

Tool은 식당 데이터를 반환한다. (가격은 1인 기준)

국밥집 한그릇: 한식, 9,000원, 회사까지 300m
라멘 이치방: 일식, 12,000원, 회사까지 500m
파스타하우스: 양식, 18,000원, 회사까지 800m
숯불갈비 명가: 한식(고기), 28,000원, 회사까지 1.5km
회센터 바다: 회/해산물, 35,000원, 회사까지 3km
호텔 뷔페 더테이블: 뷔페, 65,000원, 회사까지 1km

기본 규칙 (요청에 기준이 없을 때)
회사와 가까운 순으로 2곳을 추천한다.

답변에 포함할 내용
식당 이름, 음식 종류, 1인 가격, 회사까지 거리, 추천 이유

요청 예
"저녁 회식할 한식당을 추천해줘"
"점심에 갈 만한 만원 이하 식당을 알려줘"

# 실행 흐름
1. UI에서 출장 지역, 시작일/종료일, 예산을 입력한다.
2. 요청할 Agent(교통편/숙소/식당)를 선택하고 요청 프롬프트를 입력한다.
3. Controller는 선택된 Agent 하나만 실행하고, Agent는 자신의 @Tool로 가상 데이터를 조회해 요청에 맞게 답한다.
4. UI에 해당 Agent의 응답이 표시된다. 입력값은 폼에 유지되어 Agent만 바꿔가며 연속으로 요청할 수 있다.
